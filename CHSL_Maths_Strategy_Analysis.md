## 3️⃣ ROI LADDER — Minimum Input → Maximum Output

### 🟢 TIER 1 — Sabse pehle ye karo (input: ~25 din me 40%, output: ~11 Q/paper)
1. **Percentage** — ye sabki maa hai. Fraction↔% table ratt lo (1/8=12.5%, 1/6=16.67%...). P&L, SI/CI, DI sab fast ho jayega.
2. **Profit & Loss + Discount** — MP, CP, SP, discount chain, successive % — bas 5 models hain.
3. **Mensuration** — poori formula sheet (triangle/circle/cylinder/cone/sphere/frustum). 96% papers me aata hai, formula pata = 30 sec me answer.
4. **DI** — 0 naya concept. Bar+Table+Pie ke 480+ questions isi file me hain — roz 2 sets.
5. **Average + Ratio + SI/CI** — chhote formulae, direct questions.

### 🟡 TIER 2 — Uske baad (output: ~7 Q/paper)
6. **Algebra** — identities: (a±b)², (a±b)³, a³±b³, x+1/x patterns (x²+1/x² = (x+1/x)²−2). File me dikh raha: *x = 2+√3 type 2019 me 3 baar, aaj bhi aata hai.*
7. **Geometry** — triangles (similarity, bisectors, mid-points), circles (chord/tangent), quadrilaterals. Theorem list ~25.
8. **Trigonometry** — values table (0°–90°) + basic identities + complementary angles (sinθ=cos(90−θ)). Height-distance rare hai CHSL me.
9. **Speed/Trains/Boats** — relative speed, km/h↔m/s (×5/18), boats me (u±v).

### 🔴 TIER 3 — Kam aata hai, kam invest karo
10. Time & Work (LCM method), Number System (divisibility 7/8/9/11, unit digit), Mixture (alligation cross).
11. **Ages/Partnership ko alag se mat padho** — Ratio + Percentage ke saath automatically ho jayenge (data me sirf 0.1/paper).

## 5️⃣ REPEAT ANGLE — PYQ practice ka asli ROI

- **17% questions** aise hain jo 2+ papers me same template ke aaye (numbers change karke) — matlab **har paper me ~4 questions almost copy**.
- **25 questions verbatim same** 2+ different years me mile (e.g. *"A sum becomes Rs 1392 in 2 years..."* 2018 me 3 shifts me).
- Repeat champions: divisibility (7, 75, 88 wale 10-digit), *fourth proportional*, *x = 2+√3*, rectangle-diagonal, prime numbers 20-50.

**Matlab: PYQ solve karna = directly ~4 marks/paper ka insurance. Is file ke 2024→2022 papers first karo.**

## 6️⃣ MARKS MATH — target kya rakhein

- QA = 25 Q × 2 marks = **50 marks**, negative −0.5.
- **Target 40+** = 21 correct + 4 wrong → 42−2 = **40**.
- Attempt-all math: random guess EV = 0.25(2) − 0.75(0.5) = **+0.125 > 0** → 2 options eliminate karke guess = EV +0.33. **Koi bhi question blank chhodo mat.**
- Answer keys me koi strong letter-bias NAHI hai (2017-23: A 25%, B 26%, C 26%, D 24%) — "C mark kar dete hain" wali trick yahan kaam nahi karti. Elimination > letter-guess.

## 7️⃣ TIME & SPEED ANGLE

- Tier-I total 60 min, 100 Q → realistic maths time = **20-22 min → ~50 sec/question**.
- **34% questions pure-calculation hain** (sab options numeric) → calculation speed hi asli differentiator hai.
- Ratt lo (one-time, 2 din): squares 1–32, cubes 1–15, 1/2→1/20 tak % conversions, √2/√3/√5 values, trig 0°-90° table.
- DI me approximation use karo (options door-door hote hain — exact calc ki zarurat nahi).

### Exam-day attempt order (QA ke andar):
1. Pehli sweep (30-35 sec/Q): P&L, %, Average, Ratio, SI/CI, Mensuration-formula — jo ek line me ho jaye
2. Doosri sweep: DI sets (table pehle — values saaf dikhti hain), Speed, T&W
3. Teeji sweep: Geometry, Algebra, Trig manipulations
4. Last 2 min: bache hue — **eliminate karke guess, blank kabhi nahi**
